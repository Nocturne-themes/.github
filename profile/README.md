# Nocturne Themes

*VS Code themes for the hours between midnight and sunrise.*

Nocturne is a family of color themes built around one idea: the best light to code by is the light you'd choose for yourself at 3 a.m. — deliberate, warm or cold on purpose, never just "default dark mode." Every theme in this collection has its own mood, its own palette, and its own reason for existing.

## Getting started

Search for `Nocturne` in the VS Code Marketplace, or install any theme directly from its repository's `.vsix` release. Each theme ships as its own package — install only the ones you want.

## Philosophy

- **One mood per theme.** No mega-theme with twelve switchable variants — each repo is a single, finished idea.
- **Legible first.** Syntax contrast and UI chrome are tuned for long sessions, not just screenshots.
- **Dark and light, both deliberate.** A light theme in this collection is not an afterthought — it's built with the same care as the dark ones.

## Contributing

Found a color that doesn't sit right, or have an idea for a new theme? Open an issue on the relevant repository — contributions and suggestions are always welcome.
